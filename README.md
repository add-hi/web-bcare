# BCare – Customer Experience Complaint Management Platform

[![Next.js](https://img.shields.io/badge/Next.js-15-black?style=flat&logo=next.js)](https://nextjs.org/)
[![Vercel](https://img.shields.io/badge/Deployed%20on-Vercel-000?style=flat&logo=vercel)](https://vercel.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

🚀 **BCare** adalah platform berbasis **Next.js** yang membantu tim **Customer Experience (CX)**, khususnya agent, dalam menangani komplain perbankan secara **lebih cepat, transparan, dan terintegrasi dengan AI**.  
Aplikasi ini hadir dalam **2 platform**: Website dan Mobile Apps.

🔗 **Live Website**: [https://web-bcare.vercel.app/](https://web-bcare.vercel.app/)

---

## ✨ Fitur Utama

### 🎯 Untuk Customer Experience Agent
- **Manajemen Komplain**  
  Lihat, filter, dan kelola daftar komplain secara real-time.
- **Detail Complaint View**  
  Tinjau detail keluhan, catatan, dan update status.
- **AI Assistance**  
  Bantu agent dengan rekomendasi solusi cepat berbasis AI.
- **Transparent Tracking**  
  Setiap perubahan status dapat ditelusuri dengan mudah.
- **Role-based Access**  
  Hak akses berdasarkan divisi/role (contoh: CXC, DGO, dll).

### 📊 Tracking & Monitoring
- Notifikasi status komplain.
- Tracking transparan antar divisi.
- SLA monitoring (Service Level Agreement).

### 📱 Multi-Platform
- **Website** – akses via browser.  
- **Mobile App** – untuk agent di lapangan (dalam pengembangan).

## 🛠️ Teknologi yang Digunakan

- [Next.js 15](https://nextjs.org/) – React framework untuk produksi
- [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS framework
- [Zustand](https://github.com/pmndrs/zustand) – State management sederhana
- [Axios](https://axios-http.com/) – HTTP client untuk API integration
- [Lucide React](https://lucide.dev/) – Ikon open source
- [Vercel](https://vercel.com/) – Hosting & deployment
